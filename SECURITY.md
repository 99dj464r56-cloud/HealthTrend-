# Security policy

## Supported versions

Security fixes are made against the latest source on the `main` branch.

## Reporting

Please report security issues privately to the repository maintainer before public disclosure. Do not include real names, medical records, medicine labels, photos, JSON backups, or other personal health information in public issues or pull requests. Public Pages has no hosted health-data endpoint. The optional loopback-only local backup middleware accepts encrypted backups and exposes a configured plaintext pending recovery file to the local browser; protect that folder. Reports and raw OCR remain local.

If an issue involves a browser or dependency vulnerability, include the affected browser/version and a synthetic reproduction where possible. Never attach a real report as a reproduction.
