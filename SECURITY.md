# Security policy

## Supported versions

Security fixes are made against the latest source on the `main` branch.

## Reporting

Please report security issues privately to the repository maintainer before public disclosure. Do not include real names, medical records, medicine labels, photos, JSON backups, or other personal health information in public issues or pull requests. This application has no server-side health-data endpoint; reports and raw OCR are intended to remain in the user's browser.

If an issue involves a browser or dependency vulnerability, include the affected browser/version and a synthetic reproduction where possible. Never attach a real report as a reproduction.
